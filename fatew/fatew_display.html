韋千里四字批命： 午火月令，丁己同宮，時值己酉，己土得祿於午，生起坐下酉金，壬水日干，成為財官印生，但酉畏午之虎視，必須辛金出露，得祿於酉，印綬方能有力，如有得地通根之水，亦甚需宜。    ( 大師親算 )

  韋千里四字批命，以八字中的四個字推斷看命的方向，僅供論命參考，格局高低仍須八字全看才能論斷。



窮通寶鑑批命： 午月壬水，丁旺壬弱，取癸為用，取庚為佐，無庚不能發水，無癸不能傷丁，五月壬水，辛癸亦可參用，其理與四月皆同。庚癸兩透，科甲必然，庚壬兩透，官居極品，有庚無壬癸者，常人。或支成火局，全無金水，名財多身弱，富屋貧人，若又甲乙多者，僧道之命。

用神建議： 此造身強 (印比皆強)， 以財星為用神，食傷次之，官殺又次之。 用 丙午甲寅 優於用 丁巳乙卯。 如八字中有丙或丁透干，可優先考慮為用神。用神如貼合日主、鄰近干支生助用神，且用神未遭近剋或合化成他類五行，則為上命。用神如遇鄰近干支近剋或合化，則命格轉下。此八字喜火木運，忌水金運。 如姓名第二字與第三字之五行屬火木者吉，屬水金者凶。婚配對象，對方八字宜火木重且八字忌木者為宜。 ( 姓名學 )     ( 八字重量 )     ( 紫微斗數 )

  身弱不一定代表命不好，身強也不一定代表命好，用神有力不受沖剋，且行運大多遇到吉神，才是佳造。( 用神是什麼? )


論壬水： 壬水通河，能洩金氣。剛中之德，周流不滯。通根透癸，沖天奔地。化則有情，從則相濟。

解說： 壬水為天河水，能洩西方肅殺之氣，百川之源，周流不滯，易進而難退也。如申子辰全，又透癸水，其勢氾濫。縱有戊己之土，亦不能止其流。若強制之，反沖激而成水患。必須用木洩之，順其氣勢，不至沖奔也。合丁化木，又能生丁火。不息之妙，化則有情也。生於四五六月，柱中火土並旺。別無金水相助，火旺透干則從火。土旺透干則從土。壬水最愛寅木，因為寅中有財，不管旺衰都喜見寅木，衰水見寅木可以依託，旺水見寅木可以泄秀，不喜卯木，卯木是破子的，因此不喜。同理喜甲卻未必喜乙。
