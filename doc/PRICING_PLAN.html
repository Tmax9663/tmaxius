4不含（避免日後爭議）

  • Plus／Premium 進階功能（社交名片、AI 對話、擇日、飛星等）：另行定價，目前不開放、不報價。
  • 個人一對一命理諮詢、命書撰寫。
  • 非課程學員不適用 RM69 價（依原價 RM99）。
  • 運勢（年度命理方案）分頁目前於 Basic 未上線，屬未來更新範圍，不計入本價。

5授權與期限規則

  1. 啟動碼格式為「班級代號 + 6 位校驗碼」（例：2609A-XXXXXX），由老師／助教發放。
  2. 啟用後於學員裝置記錄 365 天；到期自動鎖回示範版（僅剩八字）。
  3. 換手機、換瀏覽器或清除資料 → 重新輸入同一組啟動碼即可，授權仍以同一學員為限。
  4. 啟動碼屬個人授權，請勿外流、轉售或公開分享。
  5. 期限一年，與課程學習週期一致。

6購買流程（建議）

學員 → 向老師／助教報名並付款 → 領取啟動碼 → 開網址輸入碼 → 立即解鎖（12 個月）
付款方式（待確認）：DuitNow QR／銀行轉帳／TnG eWallet。

8風險與建議

  • 班級共用碼有外流風險：目前機制為「一班一碼」，外流後無法逐一停權。建議改為一學員一碼，或每班碼設人數上限。
  • 期限以本機時間判定：學員改系統時間可延長。若要嚴格控管，建議加上雲端啟用紀錄（可選、非必要）。
  • 文案一致化：程式內鎖定提示提到「運勢」分頁，但 Basic 目前未掛上該分頁，建議統一說法。
