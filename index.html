About

一個人，從資料庫到印刷品One person, from database to print

我不把「工程」和「設計」分開做 —— 同一雙手，寫得出後端邏輯，也排得出海報的字距。 I don't split engineering from design — the same hands write the backend logic and set the kerning on the poster.

我是 Tmaxius，在馬來西亞檳城做軟體與設計。日常橫跨 React 與 Node.js 的應用開發、PHP + MySQL 的資料庫系統、Java 與 Flutter 的行動與終端程式，以及 Cloudflare Workers 這類無伺服器部署。 I'm Tmaxius, a developer and designer in Penang, Malaysia. My day spans React and Node.js apps, PHP + MySQL database systems, Java and Flutter for mobile and terminal software, and serverless deploys on Cloudflare Workers.

這幾年也把程式帶到硬體旁邊：Arduino 與 Raspberry Pi 的感測與控制、Kiosk 自助機的觸控流程、POS 收銀系統的票據與周邊整合 —— 從一個感測器讀值，到客人按下「結帳」那一刻，中間每一段都是我寫的。 Lately the code also sits next to hardware: sensing and control on Arduino and Raspberry Pi, touch flows on kiosks, receipt and peripheral integration on POS systems — from a sensor reading to the moment a customer taps "pay", I write every step in between.

另一隻手在設計：界面與排版、海報與印刷品、品牌視覺與資訊圖表。我習慣把「使用者第一次看到什麼」和「資料實際上怎麼跑」放在同一張桌上想。 The other hand does design: interfaces and typesetting, posters and print, brand visuals and infographics. I like thinking about "what the user sees first" and "how the data actually moves" on the same desk.

我偏好單檔、輕量、可長期維護的做法；這頁也是純 HTML、CSS 與一點點 JavaScript 寫成的 —— 沒有外部字型、沒有追蹤腳本。 I prefer single-file, lightweight, long-lived work; this page is hand-coded HTML, CSS and a little JavaScript — no web fonts, no trackers.

How I work

四個步驟，交出能用的東西Four steps, something that works

不追求一次做很大，而是每一步都留下可以驗證的成果。 Not one giant leap — every step leaves something you can check.

理解需求Understand

先把「誰要用、用來做什麼、什麼時候會壞」問清楚，再決定技術。Ask who uses it, what for, and how it breaks — then pick the technology.

設計Design

資料結構與畫面一起畫，先確認資訊順序，再談風格與細節。Sketch schema and screen together; settle the order of information before style.

實作Build

小步交付、實際測試；能用單純寫法解決的，就不多加一層。Ship in small steps, test for real, and never add a layer a simpler approach avoids.

上線與維護Ship & maintain

部署、驗證、寫下交接說明；後續的調整與優化也一起照顧。Deploy, verify, write the handover notes, and stay for the tweaks afterwards.
