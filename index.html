About · 關於我

一個人，從資料庫到印刷品

我不把「工程」和「設計」分開做 —— 同一雙手，寫得出後端邏輯，也排得出海報的字距。

我是 Tmaxius，一位在馬來西亞檳城的軟體開發者與設計師。日常的工作橫跨 JavaScript / Node.js 的應用開發、PHP + MySQL 的資料庫系統、 以及 Cloudflare Workers 這類無伺服器（serverless）部署； 版本控制、指令列自動化、上線維運也都是自己來。

另一隻手則在設計：界面與排版、海報與印刷品、品牌視覺與資訊圖表。 我習慣把「使用者第一次看到什麼」和「資料實際上怎麼跑」放在同一張桌上想， 所以交付的東西通常不是只有功能，而是整體說得通的一件作品。

我偏好單檔、輕量、可長期維護的做法：能用原生技術解決的，不急著堆框架； 能寫清楚的，就不用人猜。這頁也是這樣寫成的 —— 純 HTML、CSS 與一點點 JavaScript， 沒有外部字型、沒有追蹤腳本。

手機方面我也自己走完整條路：Android（Kotlin）與 Flutter（Dart） 都做， 從介面、狀態管理、離線資料、到打包與發佈；其中一支是路上司機每天在用的行車翻譯工具， 另一支是我自己排命盤、出報告用的八字 App。
