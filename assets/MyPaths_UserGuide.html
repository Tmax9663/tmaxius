1. 簡介

MyPaths 生命數據庫是一款八字（四柱）命理分析應用，透過您輸入的出生日期、時辰與性別， 即時排定四柱八字，並提供五行、格局、運勢、飛星、V數、易占（梅花易數）、AI 命理報告與擇日等多項分析。

主要功能

  • 八字（四柱）即時顯示：年、月、日、時四柱，含主星、藏干、副星、納音、星運、神煞與大運。
  • 五行分析：日主強弱、喜用神、五行分佈。
  • 格局／運勢：命理方案與年度深度分析、大師建議。
  • 飛星與 V數：玄空飛星盤與生命數字分析。
  • 易占：梅花易數年月日時法斷吉凶。
  • AI 命理報告：自備 Gemini API Key，生成詳細命理解說。
  • 擇日：農民曆宜忌、建除十二值、四離四絕、天赦日等。
八字四柱在瀏覽器本地即時計算，修改生日立刻更新；完整的深度分析由伺服器計算， 點擊「開始分析」後才會在各分頁顯示結果。
本指南僅供說明操作與解讀方式，命理結果屬娛樂參考性質，請勿盲目迷信。

  • 年：選擇西元 1900–2030；月／日／時／分以下拉選單選擇，日會依月份自動顯示正確天數。
  • 性別：選擇「男」或「女」，命盤會顯示「乾造」或「坤造」。
  • 時辰徽章會即時顯示所選時間對應的時辰（子時～亥時），點「重設」可恢復為現在時間。

2.2 觀看命盤與開始分析

  • 每次修改年／月／日／時／分／性別，下方的八字四柱表會立即更新，不需等待。
  • 其他分頁（五行、格局、運勢、飛星、V數、易占、AI、擇日）需先點擊「開始分析」才會計算並顯示結果。
  • 分析完成後「開始分析」按鈕會隱藏；修改任何日期／時辰／性別後按鈕重新出現，再點一次即可重新計算。
  • 若當日或當分鐘次數已達上限，會提示「已達今日分析次數上限」或「操作太頻繁」。

2.3 儲存多位使用者與查詢年

  • 輸入姓名後按「＋」即可把目前生日資料存入「資料列表」，之後可一鍵載入；按「－」刪除。資料加密儲存於本機瀏覽器。
  • 八字分頁右上角可調整「查詢年」，大運、流年與起運資訊會依查詢年計算。

3. 如何解讀命盤結果

3.1 八字四柱表

表格由左至右依序為年、月、日、時四柱，加上大運與流年，例如：

納音 大溪水 泉中水 桑柘木 天上火 路旁土
  • 主星（十神）：比肩、劫財、食神、傷官、偏財、正財、七殺、正官、偏印、正印，表示日主與各柱的關係。
  • 天干／地支：天干為「外在」、地支為「內在」，顏色代表五行（木綠、火紅、土黃、金褐、水藍）。
  • 藏干：地支內藏的天干，代表內在潛藏的力量；副星為藏干相對日主的十神。
  • 納音：如海中金、爐中火、大林木等；星運（十二長生）描述日主在該地支的旺衰狀態。
  • 神煞：天乙貴人、文昌、桃花、學堂、五鬼、天狗、血刃等吉凶神煞。

表格上方顯示農曆日期、起運歲數、順運或逆運與目前大運；下方另有「大運序列」表。

3.2 各分析分頁

  • 五行分頁：日主身強弱（得分與等級）、喜用神與忌神、五行分佈與十神象義。
  • 格局分頁：貴人與格局分析；運勢分頁：年度深度分析與大師建議（命理方案）。
  • 飛星：玄空飛星盤吉凶方位；V數：生命數字分析。
  • 易占：梅花易數年月日時法起卦，顯示本卦、互卦、變卦、體用生剋與吉凶百分比。
  • AI 命理報告：設定 Gemini API Key 後生成白話命理報告。
  • 擇日：農民曆宜忌、建除十二值、節氣、四離四絕與天赦日，方便挑選吉日。

4. 常見問題解答（FAQ）

Q：為什麼其他分頁顯示「請先點擊開始分析」？
八字四柱表是本地即時計算；其餘深度分析由伺服器計算，為控制使用次數與伺服器負載， 需先點擊「開始分析」按鈕，各分頁才會計算並顯示結果。
Q：點「開始分析」時提示「已達今日分析次數上限」怎麼辦？
免費訪客每日 30 次、每分鐘 5 次（每次完整分析計 1 次）。超過上限請明天再試； 升級 API Key（plus／premium）可獲得更高額度，等級額度如下表。

管理員 admin 5000 300 管理員專用
Q：什麼是 API Key？要如何取得？
API Key 是管理員發給使用者的金鑰，用來識別等級並提高分析次數上限。請到「個人」頁， 點「WhatsApp 申請」，填好姓名、Email 並選擇等級（free／plus／premium）， 訊息會自動帶入以上資料傳送給管理員；管理員收到後會建立對應等級的 API Key 並回傳給您。
Q：拿到 API Key 後要輸入到哪裡？
點擊右上角的「個人資料」按鈕進入「個人」頁，在「API Key」欄位貼上金鑰， 按「儲存並驗證」，即可看到您的等級、額度與今日用量。
Q：「管理後台」是什麼？一般人能用嗎？
「管理後台」位於個人頁內，需輸入管理員 Token 才能使用，只有管理員可建立／撤銷 API Key。 一般使用者看不到管理功能。
Q：這些命理結果準確嗎？
本應用以農民曆、八字、五行等傳統演算法計算，結果僅供娛樂與參考， 不可盲目迷信，重大決策請尋求專業意見。
Q：如何列印命盤？可以儲存多位使用者嗎？
點擊右上角的列印按鈕即可列印；輸入姓名後按「＋」即可儲存多位使用者到「資料列表」，隨時載入。
Q：AI 報告需要另外付費嗎？資料會上傳嗎？
AI 報告使用您自己的 Gemini API Key（由 Google 依其方案計費，本應用不額外收費）； 姓名、生日與 Email 等個人資料儲存在您本機瀏覽器，伺服器不回存個人資料。
