如何免费获取 Gemini API Key

  1. 前往 Google AI Studio 并使用 Google 账号登录。
  2. 点击页面左上方或右上方的 "Create API key" (创建 API 密钥) 按钮。
  3. 选择 "Create API key in new project" (或选择已有的 Google Cloud 项目)。
  4. 复制生成的以 AIzaSy... 开头的长字符串。
  5. 粘贴到本页面的 Gemini API Key 输入框中即可（系统会自动保存在本地浏览器中）。

* 注：Gemini 提供免费额度（Free Tier），无需绑定信用卡即可直接使用。
